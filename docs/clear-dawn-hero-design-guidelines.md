# Clear Dawn Hero UI v1 — デザインガイドライン

## 目的と適用範囲

Clear Dawnのブランド「夜明け前の静けさから、今日の一歩へ」を視覚化するヒーローカード型のUI。
**対象はClear Dawnのログイン後の全画面のみ。Kioku / Yoyu / 認証系 / 公開ランディングページには適用しない。**

基準リポジトリ: tai-namechan/Clear-Dawn-v0、main \`dfceb542d191711c9da2b849f9751a96432fa79a\`。
既存のLaravel13 / Vue3 / Inertia3 / Tailwind4 / ECharts / Wayfinderと共存する。UIのみを変更しDB、API、業務処理を変更しない。

## コンセプト

- **Hero:** 最初に今日・この画面で重要な事実だけを大きく見せる。落ち着いた夜明けの地平線を背景にする。
- **Overview:** 最重要数値は大きく、補助数値は小さく。平面的な6分割カードを減らす。
- **Trends:** 長期推移は白いカード上のチャートで読みやすく。折れ線・PFCの実測値を優先する。
- **Record & Action:** 保存・記録・開始などの主要操作は常に明確なボタンとして見せる。
- **Next step:** データから判断できない提案をAIのように装わない。提案がないときは断定的なAI文言を表示しない。

## v3 改訂（2026-11-22）: 和モダン背景

v2 の「写真の空ヘッダー」と大理石背景をやめ、画面ごとの和モダン背景（和紙・山景・金線）に切り替える。v2 と矛盾する場合は本節を優先する。

| 画面 | 背景 | 対象ページ |
|---|---|---|
| 今日 | 桜と朝日 `cd-wa-today-*` | 目標、領域 |
| 食事 | 菖蒲と麻の葉 `cd-wa-food-*` | 食事・食品 |
| コンディション | 竹 `cd-wa-condition-*` | パフォーマンス管理・コンディション・記録詳細 |
| 実行・練習 | 紅葉 `cd-wa-practice-*` | ルーティン・プラン・セッション・プログラム・実施項目・履歴・動画 |
| 設定 | 五重塔と青海波 `cd-wa-settings-*` | 設定、ダッシュボード（マトリクス。桜が主張しすぎるため） |

- 背景は `public/images/backgrounds/cd-wa-{scene}-{sp|pc}.webp`。幅 768px 未満は SP（縦）、以上は PC（横）。
- 背景はスクロール領域（`.cd-clear-app`）の背景として敷き、内容だけがスクロールする。`background-attachment: fixed` は使わない（iOS Safari）。
- 背景は明るいため、**ヒーローの見出し・ヘッダー・操作は濃い文字（Ink `#211F41`）**にし、白字やテキストシャドウは使わない。空の上のすりガラスは白基調にする。
- 装飾は意図的に薄い。カード・入力欄は白地のまま十分なコントラストを保つ。
- **配色（2026-11-22 追記）:** ベース（和紙）`#FBF7EF`、朝霞（紫灰）`#EEEAF6`、藍墨（山影）`#DCD6E8`、金 `#D4B370`。
  - カードは半透明の和紙色 `rgba(251,247,239,.9)` に淡い茶系の枠。白（`bg-white`）も和紙色に置き換える。
  - Primary は藤色 `#6F68AD`（ボタン・選択中タブは `#9A93CF → #6C64A8` のグラデーション）。カード内の小タイル・タブの下地は朝霞。
  - 見出しの下線・リング・進捗の一部は金。食事の摂取リングは藤色、ルーティンの実行リングは金。
- **マトリクスのフォーカスカード（スマホ）:** 通常のカード。項目はPCのマトリクスと同じ `font-matrix`。
- **書体（2026-11-22 追記）:** ページ見出しとカード見出しは明朝（Shippori Mincho）。数値・本文はゴシックのまま。

## v2 改訂（2026-11-21）: 写真の空ヘッダー

モックアップ（ヒーローカード型 UI リニューアル）に近づけるため、v1 から次の点を変更する。v1 の記述と矛盾する場合は本節を優先する。

- **背景:** ヒーローの背景を軽量 SVG から写真調の夜明けの空 `public/images/backgrounds/cd-sky-dawn.webp`（WebP・約 36KB）に変更する。空はカードではなく**ページ上部の全幅背景**で、ヘッダーとヒーローの後ろに敷く。下端は徐々にページ背景へ溶かす。
- **ヒーロー:** 暗いカードをやめ、空の上に白字で直接置く。ヒーローの数値（`PageTabShell` の `hero` スロット）は空の下端に重なる白いサマリーカードに入れる。空の高さはヒーローの下端に合わせて自動で決める（`CdSkyBackdrop.vue`）。
- **ヘッダー:** 空の上に透明で重ねる。モバイルでも上部に固定しない（移動は下部ナビで行う）。
- **ページ背景:** ダッシュボード（マトリクス）は従来の大理石（`dairiseki.png`）を維持する。それ以外の画面は薄紫 `#F7F5FB`。
- **Primary:** `#6B5AED` を主要ボタン・選択中タブ・下部ナビの選択状態に使う（`.cd-clear-app` 配下のみ）。
- **下部ナビ:** 選択中の項目は枠で囲まず、アイコンと文字を Primary にする。項目・順番・アイコンはサイドバーと同じ（ダッシュボード / ルーティン / パフォーマンス管理 / 食事 / 設定）。幅が狭いため表示名だけ短くする（ホーム / ルーティン / 記録 / 食事 / 設定）。定義は `resources/js/lib/clearDawnNavigation.mjs` に一本化する。
- **目標・動画:** サイドバー・下部ナビには置かず、ルーティン画面のヒーロー操作（プログラムの隣）に入口を置く。表示中はルーティンを選択状態にする。
- **書体:** ページ見出し・タブはゴシック（Noto Sans JP）に統一する。ブランドのワードマーク「Clear Dawn」はセリフのまま。
- **空の明るさ:** オーバーレイは紺ではなく薄い紫にし、モックアップのような明るい紫の空を保つ。
- **ボタン:** 主要ボタン・選択中タブは `#8064F5 → #5E45DF` の紫グラデーション（単色だと青寄りに見えるため）。
- **ガラスカード:** 記録画面の達成率カードは空の上に重なる半透明の紫ガラス（`cd-glass-panel`、白字）。空はこのカードの下まで伸ばす（`data-sky-extend`）。
- **ヒーローの無い画面:** パスワード確認など見出しが暗色の画面では、空はヘッダーの後ろだけに敷く。
- **パフォーマンス管理画面:** コンディション中心にする。睡眠・体重・疲労度・痛み・しびれ（＋最高球速）のカードを空の上に並べ、各カードは指標の詳細へリンク。疲労度・痛みは 1〜5 のバー（疲労度はゴールド、痛みは紫）。「今日のコンディションを記録」ボタン、最近の推移（7日間）は睡眠時間・体重（ゴールド）・疲労度のカードと平均値。PFC・カロリー達成率は食事画面に一本化し、ここでは表示しない。
- **食事画面:** 摂取リングと「残り」バッジはゴールド（`--cd-gold`）。PFC は文字チップと目標に対する進捗バー（PFC の色は既存の semantic token のまま）。記録の入口はバーコード・食品検索・写真の3タイルと近道リスト。本日の食事は朝・昼・夕ごとの行にまとめ、タップで中身（編集・コピー・削除）を開く。

## 生成アセットと役割

- \`public/images/decorations/cd-hero-dawn.svg\` — 夜明けの稜線・空。実際の画像生成で検討した3つのシーンから輪郭・配色を抽出した軽量SVG。UI側へテキストを焼き込まない。
- \`public/images/decorations/cd-hero-halo.svg\` — 光輪。ローディングや装飾用であり、値を示す進捗リングはHTML/CSSで描画。
- \`public/images/decorations/cd-hero-stars.svg\` — 星屑の微細な装飾。画像は読み上げず、CSS背景に限定。
- 写実的な背景の高精細素材は参考画像として別納品。アプリ内では軽量SVGを使うため、通信・LCP・レイアウト安定性を優先する。

## 数字とカード

- 最大主要値: \`clamp(1.5rem,6vw,2.7rem)\`、tabular numerals。単位は小さく表示。
- ヒーロー・主要カード: 24〜26px radius、弱い影、余白20〜44px。
- 補助情報: 16〜18px radius。テーブル・設定フォームは白地を保つ。
- ラベルを先、数値を後。比率と母数を併記（例: 2,715 / 2,550 kcal、目標比106%）。
- 100%超は上限に丸めたリング＋**本当の割合を文字**で表示。目標超過を自動的に成功と判定しない。
- 未入力はダッシュ/「未記録」。「0」を捏造しない。

## コンポーネント構成

- \`CdHeroBanner.vue\`: データの有無に依存しない共通ヒーロー。ダッシュボードで利用。
- \`PageTabShell.vue\`: 空の上のヒーロー（見出し・カレンダー・操作）、白いサマリーカード（\`hero\` スロット）、タブと本文の白いカードに分ける。アクセシビリティ維持。
- \`CdSkyBackdrop.vue\`: ページ上部の空の背景。最初のヒーローの下端を測って高さを決める。
- \`PageTitleOrnament.vue\`: 従来のページ見出しを保持しつつ、ヒーロー上で白字として扱う。
- \`PageSectionCard.vue\`: 共通の情報面。既存propsを維持。
- \`CdMobileNav.vue\`: モバイル用5タブ。サイドバー（\`AppSidebar.vue\`）と同じ項目定義を使う。
- \`resources/css/clear-dawn-hero.css\`: **\`.cd-clear-app\`配下に限定**したトークンと装飾。

## 画面幅・アクセシビリティ

- 320px、375px、390px、768px、1024px、1440pxで確認。
- iPhone Safari下部のsafe area（\`env(safe-area-inset-bottom)\`）を考慮。
- 白いカードには濃色文字。ヒーロー上は白字と暗いオーバーレイ。
- focus-visible、44px程度のタッチ領域、スクリーンリーダー用のaria-label。
- reduced-motion時は余分な装飾アニメーションを停止。
- テキスト・グラフの実数値を画像へ焼き込まない。SVGは装飾専用。
- 画像に個人情報・体重・食事写真等を含めない。
