# ルーティン実行システム仕様

対象フェーズ: Phase 2（Milestone M3）— Routine System 転換後

## 目的

習慣・練習・学習を共通の「ルーティン実行」フローで管理する。

```
実施項目（ステップで使う項目）
  ↓ 組み合わせる
ルーティン（再利用テンプレート）
  ↓ 日付を付けて生成
今日の実行プラン（当日版スナップショット）
  ↓ 開始
実行セッション（進行中〜完了）
  ↓ 蓄積
ブロックログ（不変の事実ログ）
```

## 画面とルート

| 画面 | ルート | 役割 |
|---|---|---|
| ルーティン（サイドバー着地） | GET /routines | ページ内タブ **今日 / ルーティン / 履歴**。実行の本拠 |
| ルーティン編集 / 作成 | GET /routines/create, /routines/{id} | テンプレのステップ編集 |
| プログラム一覧 | GET /programs | サイドバーには出さない。`/routines` ヘッダーから行き、戻れる |
| 今日/作戦（互換） | GET /today | `/routines` へリダイレクト。API は `/today/*` 維持 |
| 履歴（フル） | GET /history | 履歴タブの「すべて見る」先 |

| 画面 | ルート | 役割 |
|---|---|---|
| 実施項目（整理用・主導線外） | GET /routine-items | 普段は不要 |
| S6 プラン詳細 | GET /plans/{id} | 当日調整・セッション開始 |
| S7 実行画面 | GET /sessions/{id} | ブロックログ入力 |

### ナビ方針

- **サイドバー**: ダッシュボード / ルーティン / パフォーマンス管理 / 目標 / 動画 / 設定（プログラムは置かない）
- **横ハブタブ（プログラム・ルーティン・履歴の並び）は使わない**。ページ内タブで足りる
- プログラム一覧への導線は `/routines` ヘッダーの「プログラム」のみ（戻るリンク付き）

### GET /routines の構成（データがある日）

ページ内タブ: **今日 / ルーティン / 履歴**

#### 今日タブ（第一ビュー）

上から優先順:

1. **今日のセッション + 食事の残り**（同一段・主コンテンツ）
   - 左: 日付ナビ・完了数 / 進捗 / 予定時間・プランカード一覧（開始・続ける）
   - 右: 残り kcal / PFC・食事記録 / コンディションへのリンク
2. **主作戦カード 1 件**（あれば・二次。チェックイン催促カードは出さない）
3. **チェックイン**（1 つだけ。未入力ならパネル、済なら薄いバー）

プランが無い日はセッション側を空状態（ルーティンタブへ誘導）にし、食事・作戦・チェックインは出せるものは出す。

#### ルーティンタブ

再利用テンプレ一覧（編集 / 今日に追加）。`?tab=routines`

#### 履歴タブ

直近履歴。詳細は `/history`

### データがある日の画面マップ（ルーティン機能）

| 画面 | 主なブロック（上→下） | 空のとき |
|---|---|---|
| 今日 | ①セッション（進捗+プランカード）＋食事の残り ②主作戦1件 ③チェックイン | セッション空状態＋ルーティン/プログラム誘導。食事・作戦・チェックインは出せるものだけ |
| ルーティン | テンプレ一覧（今日に追加 / 詳細 / 編集） | 「最初のルーティンを作る」 |
| 履歴 | 直近ログ一覧 | 「まだ履歴がありません」 |
| プログラム一覧 | ←ルーティン戻る / 一覧 / ロードマップ入口 | install 案内 |
| プラン詳細 / 実行 | S6 は ready でもステップ編集可（動画紐付け含む）。実行中セッションのスナップショットは不変 | 変更なし |

- 当日プラン: `GetTodayQuery`（`?date=` 対応）
- 作戦・栄養: `GetTodayOpsQuery`
- プラン生成・ルール評価は表示時に実行
- DB スキーマ変更なし / サイドバー項目追加なし（プログラムは削除）

## API（主要）

| 操作 | ルート |
|---|---|
| プラン / セッション / ブロック | 既存どおり |
| ルーティン CRUD | /routines |
| チェックイン等 | `/today/checkin` 等（パス維持） |

## 設計原則

1. **主導線は今日の実行。** セッション開始と食事の残りを最初に見せる。
2. **プログラムは上位設定。** 一覧は残すがサイドバー・ハブタブには出さない。
3. **二重ナビを作らない。** 横ハブとページ内タブを重ねない。
4. **冗長カードを出さない。** チェックイン UI と催促カードを重ねない。主作戦は 1 件まで。
5. **サイドバーは最小。** 着地は `/routines`。プログラム項目は置かない。
6. **データ構造は変えない。**
