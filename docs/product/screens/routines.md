# ルーティン実行システム仕様

対象フェーズ: Phase 2（Milestone M3）— Routine System 転換後

## 目的

習慣・練習・学習を共通の「ルーティン実行」フローで管理する。

```
実施項目（ステップで使う項目）
  ↓ 組み合わせる
ルーティン（再利用テンプレート）
  ↓ 日付を付けて生成
今日の実行プラン（当日版スナップショット）
  ↓ 開始
実行セッション（進行中〜完了）
  ↓ 蓄積
ブロックログ（不変の事実ログ）
```

## 画面とルート

| 画面 | ルート | 役割 |
|---|---|---|
| ルーティン（サイドバー着地） | GET /routines | ページ内タブ **今日 / ルーティン / 履歴**。実行の本拠 |
| ルーティン編集 / 作成 | GET /routines/create, /routines/{id} | テンプレのステップ編集 |
| プログラム一覧 | GET /programs | サイドバーには出さない。`/routines` ヘッダーから行き、戻れる |
| 今日/作戦（互換） | GET /today | `/routines` へリダイレクト。API は `/today/*` 維持 |
| 履歴（フル） | GET /history | 履歴タブの「すべて見る」先 |

| 画面 | ルート | 役割 |
|---|---|---|
| 実施項目（整理用・主導線外） | GET /routine-items | 普段は不要 |
| S6 プラン詳細 | GET /plans/{id} | 当日調整・セッション開始 |
| S7 実行画面 | GET /sessions/{id} | ブロックログ入力 |

### ナビ方針

- **サイドバー**: ダッシュボード / ルーティン / パフォーマンス管理 / 目標 / 動画 / 設定（プログラムは置かない）
- **横ハブタブ（プログラム・ルーティン・履歴の並び）は使わない**。ページ内タブで足りる
- プログラム一覧への導線は `/routines` ヘッダーの「プログラム」のみ（戻るリンク付き）

### GET /routines の構成（データがある日）

ページ内タブ: **今日 / ルーティン / 履歴**

#### 今日タブ（第一ビュー）

上から優先順（2026-11-22 改訂: セッションの実行に集中する）:

1. **今日の実行サマリー**（空の下端に重なる白いカード）
   - 「本日の実行 完了数 / 全体」のリング、今日のセッション名のチェックリスト（完了 ✓ / 未完了 —）、日付ナビ
2. **今日のセッション一覧**
   - 各カード: アイコン・タイトル・状態・ステップの進み具合（処理済み / 全ステップのバー）・開始 / 続ける
   - 下に「ルーティンから追加」

食事の残り・主作戦カードはこのタブに出さない（食事は食事画面、作戦エンジンの結果は画面に出さない）。30秒チェックインは 2026-11-22 に廃止（[today-ops.md](./today-ops.md)）。

プランが無い日はセッション側を空状態（ルーティンタブへ誘導）にする。

#### ルーティンタブ

再利用テンプレ一覧（編集 / 今日に追加）。`?tab=routines`

#### 履歴タブ

直近履歴。詳細は `/history`

### データがある日の画面マップ（ルーティン機能）

| 画面 | 主なブロック（上→下） | 空のとき |
|---|---|---|
| 今日 | ①実行サマリー（リング＋チェックリスト）②セッション一覧（進み具合バー） | セッション空状態＋ルーティン/プログラム誘導 |
| ルーティン | テンプレ一覧（今日に追加 / 詳細 / 編集） | 「最初のルーティンを作る」 |
| 履歴 | 直近ログ一覧 | 「まだ履歴がありません」 |
| プログラム一覧 | ←ルーティン戻る / 一覧 / ロードマップ入口 | install 案内 |
| プラン詳細 / 実行 | S6 は ready でもステップ編集可（動画紐付け含む）。目標値など実行中セッションのスナップショットは不変。ただし未完了ステップへの動画紐付けは実行中セッションへ同期する | 変更なし |

### 実行画面のステップ表示（S7）

セッション開始時に `routine_plan_steps.note`（キュー・今週の処方）を
`routine_session_steps.note` へスナップショットする。実行画面はこれを `' / '` で分割し、
1行目を主文、以降を補足として「ポイント」カードに表示する。

| 表示 | 出どころ | 備考 |
|---|---|---|
| 動画 | `video_id`（プラン → 実施項目の既定動画の順で解決） | 無い場合は動画エリアが空状態になる |
| ポイント（キュー） | `routine_session_steps.note` | 開始時点で固定。プランを後から書き換えても変わらない |
| メモ | `routine_session_steps.memo` | 実行中に自分で書く欄 |

動画とキューは排他ではない。動画が後から紐付けられれば動画が出て、キューはそのまま残る。
キューは生成AIで作らない（フォームの正確さが要る領域で、生成画像・生成文は誤りを持ち込むため）。

- 当日プラン: `GetTodayQuery`（`?date=` 対応）
- 作戦・栄養: `GetTodayOpsQuery`
- プラン生成・ルール評価は表示時に実行
- DB スキーマ変更なし / サイドバー項目追加なし（プログラムは削除）

## API（主要）

| 操作 | ルート |
|---|---|
| プラン / セッション / ブロック | 既存どおり |
| ルーティン CRUD | /routines |
| チェックイン API | `/today/checkin` 等（互換のため残置。画面からは未使用） |

## 設計原則

1. **主導線は今日の実行。** セッションの開始と進み具合を最初に見せる。
2. **プログラムは上位設定。** 一覧は残すがサイドバー・ハブタブには出さない。
3. **二重ナビを作らない。** 横ハブとページ内タブを重ねない。
4. **冗長カードを出さない。** 主作戦は 1 件まで。
5. **サイドバーは最小。** 着地は `/routines`。プログラム項目は置かない。
6. **データ構造は変えない。**
