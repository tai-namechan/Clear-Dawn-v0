# 「今日/作戦」画面 仕様

対象: セルフマネジメントOS拡張 Phase 2〜4（2026-07-16 確定）
関連: [programs.md](./programs.md)、[routines.md](./routines.md)、[ADR-0011](../../adr/0011-five-data-kinds-and-rule-engine.md)

## 目的（2026-07-25 更新）

旧 `/today`（今日/作戦）の役割は **`/routines` の「今日」タブに巻き取り済み**。
作戦カード・チェックイン・セッション開始を 1 画面にまとめ、ハブの「今日/作戦」タブは廃止する。

`GET /today` は互換のため `/routines` へリダイレクトする。
チェックイン等の API（`PUT /today/checkin` など）はパスを維持する。

**ダッシュボード（TOP Matrix）とは別物であり、変更しない。**

詳細な画面構成は [routines.md](./routines.md) の「今日タブ」を正とする。

## 今日タブに残すもの / 出さないもの

| 残す | 出さない |
|---|---|
| 主作戦カード 1 件 | 「その他の作戦」の羅列（特にチェックイン催促の二重表示） |
| チェックイン UI は 1 つだけ | チェックインパネルと同時に出す「チェックインを記録」カード |
| メインセッション開始 | 食事残り・セッション一覧の過剰な再掲（必要なら薄い二次） |

## ルール（エンジン側・変更なし）

- 作戦カードは決定論エンジン（Phase 4）が生成。承認されるまで今日のプランは変わらない。
- 承認は 3 段のうち A（今日のみ）をこの導線で完結。B/C はプログラム画面へ誘導。
- 割り込み提示はハードゲート（H1〜H7）のみ・1 日 1 件まで。
- 較正期間（データ蓄積 4 週未満）は警告系カードを出さず「較正中」と表示。

## 日付・タイムゾーン

- **日付の正はユーザー TZ**（`users.timezone` → `UserTimezoneResolver`）。
- チェックイン・症状観察・プログラム選択の「今日」既定値はユーザー TZ のカレンダー日（`Y-m-d`）。

## チェックイン API（部分更新）

- `PUT /today/checkin` は **送信されたフィールドのみ更新**する（部分更新）。
- 未送信の `note` / `region_tension` 等は既存値を保持する（null 上書きしない）。
